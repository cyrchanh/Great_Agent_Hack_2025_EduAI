PRISM-X puts a governance layer, AEGIS X, in front of an LLM agent. An intent classifier and an LLM Guardian screen every request, and a red-team Attacker keeps probing, with every attack that slips through fed back into the Guardian's prompt. This page compares it with the keyword filter we used as a baseline.

        A red team that teaches the guard

        The Guardian doesn't retrain. When an attack gets through, it is stored and the five most recent misses are written into the Guardian's prompt for the next decision. Mark an attack as "slipped through" to see the prompt change.

        Where the attacks come from
        1. Scrape arXiv5 of the newest papers on adversarial ML, with an LLM pass over each one's limitations and future work
        2. Connect papersan LLM finds links between papers and proposes combinatorial attacks and defences that join their ideas
        3. Mine the webValyu search for real jailbreak and prompt-injection patterns
        4. Red-team roundsin three modes: hardcoded, research-derived and combinatorial
        5. Learn from missesevery attack that is allowed through goes into the Guardian's pattern memory
        The first three are the system's hardcoded attacks. The last two are written in the style of research-derived and combinatorial attacks and are only examples.

        The agent being governed: NOVA

        The second half of PRISM-X is a 4-node LangGraph pipeline that turns a few keywords into validated research ideas. In the prototype it runs as a separate module from AEGIS X, and the React chat UI is its front end.

        01

        Scraper

        Valyu search for papers matching the user's keywords, filtered by a relevance threshold

        02

        Summarizer

        Pulls the 3 to 5 most interesting ideas out of each paper

        03

        Idea generator

        Combines ideas from 2 or more papers into 5 to 7 new research directions

        04

        Validator

        Keeps only the ideas that are actually new compared to the source papers
